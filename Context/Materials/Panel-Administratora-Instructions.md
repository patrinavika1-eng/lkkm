Руководство пользователя

# Панель администратора

> ⓘ Работать с панелью администратора могут только пользователи с административной ролью.
>
> Подробнее в разделе [Возможности ЛК КМ].

Вы можете выбирать ответственных внутри групп в разделе **Панель администратора**.

В зависимости от роли вы можете назначать администраторов только для своей группы или групп, которые находятся у вас в подчинении. Слева от названия вашей группы отображается [жёлтая звезда].

## Как назначить администратора

Чтобы назначить администратора внутри группы:

1. Нажмите [иконка профиля] → **Панель администратора**. Откроется **Матрица доступов**.
2. Нажмите [иконка карандаша] в строке с группой.
3. В поле **Администратор группы** выберите ответственного для выбранной группы.
4. Нажмите **Сохранить**.
