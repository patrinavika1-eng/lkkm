## Действия Менеджера

### Работа с запросом — общее
- При переходе в карточку запроса сотрудник видит только релевантные для него дирекции /финкоды и товары в запросе, которые ему необходимо отработать
- Сотруднику доступно 3 сценария отработки позиций: – Через чекбоксы  – Через кнопки в нижней панели  – Через переход внутрь каждого финкода/дирекции
- При точечной работе через чекбоксы - в кнопках учитывается только то, что выбрано через чекбокс
- Другие кнопки действий блокируюются
- Для перехода внутрь дирекции/финкода необходимо кликнуть на строку / кнопку “Отработать” / шеврон со стрелкой
- Внутри дирекции/финкода видим список позиций, который сотруднику необходимо отработать
- Сотруднику доступно 2 сценария отработки позиций: – Через чекбоксы  – Через кнопки в нижней панели

### Разводящий экран: массовые действия на панели действий
- Для согласования необходимо нажать на кнопку “Согласовать все”
- Для отклонения необходимо нажать на кнопку “Отклонить все”
- Для отправки на доработку необходимо нажать на кнопку “На доработку все”
- Модальное окно для подтверждения действия → Ошибка → Успех
- Прогресс бары - заполнены; Чекбоксы - не отображаются
- Внутри дирекции/финкода все позиции согласованы / отклонены; Чекбоксы не отображаются; Прогресс-бар заполнен
- Успех – запрос отправлен
- Сотруднику доступны действия, кроме запроса доработки
- Тултип за кнопке запроса доработки и статуса
- Позиция может вернуться с доработки потсавщика удаленной (поставщик сам удалил данную позицию из запроса), она возвращется в статусе “Удалено поставщиком”, сама строка дизейблится и более не участвует в согласовании
- [стикер] Этот кейс будем реализовывать после 10.06

### Разводящий экран: массовые действия через чекбокс
- Для согласования необходимо выбрать чекбоксы и нажать на кнопку “Согласовать”
- Для отклонения необходимо выбрать чекбоксы и нажать на кнопку “Отклонить”
- Для отправки на доработку необходимо выбрать через чекбокс нужные фин/дир и нажать на кнопку “На доработку” с каунтером, где каунтер-количество выбранных фин/дир
- Прогресс бары у выбранных строк - заполнены; Чекбоксы на отработанных строках задизейблены

### Экран дирекции/финкода: массовые действия
- Для согласования необходимо нажать на кнопку “Согласовать все”
- Для отклонения необходимо нажать на кнопку “Отклонить все”
- Для отправки на доработку необходимо нажать на кнопку “На доработку все”
- Все позиции с этого экрана отправятся на доработку поставщику
- Чекбоксы не отображаются; Прогресс-бар заполнен; Тултипы

### Экран дирекции/финкода: массовые действия через чекбокс
- Для согласования необходимо выбрать строки через чекбокс и нажать на кнопку “Согласовать”
- Для отклонения необходимо выбрать строчки через чекбокс и нажать на кнопку “Отклонить”
- Для отправки на доработку необходимо выбрать через чекбокс позиции и нажать на кнопку “На доработку” с каунтером, где каунтер - количество выбранных позиций
- Все выбранные позиции отправятся на доработку поставщику
- Чекбоксы на отработанных строках неактивны; Прогресс-бар заполнен в соответствии с количеством отработанных позиций
- Через мета-чекбокс можно выбрать и массово отработать только неотработанные позиции

## Действия Капитана
- Помимо действий как у менеджера капитану доступно: – консолидация запросов на доработку от менеджеров и отправка на доработку запроса поставщику – формирование рекомендаций для руководителя, доступно по кнопке “Сводка решений”
- Действия капитана полностью аналогичны действиям менеджера
- Кнопки действий пропадают в случае, когда капитан, который сам является еще и менеджером, отработал позиции
- Если хотя бы 1 менеджер запросил доработку – это отображается в сводке решений и в листе согласования
- Капитан отправил предварительное решение поставщику, необходимо дождаться, когда запрос снова вернется в работу с уточнениями и правками
- Если у позиций нет запросов на доработку, то после всех согласований капитан может сформировать рекомендации и отправить руководителю для финального решения
- Рекомендации отправлены руководителю

### Сводка решений
- В сводке решений отображаются позиции со статусами Этот список уйдет поставщику на доработку
- Капитан может выбрать через чекбокс комментарии менеджеров для уточнения, а так же может добавить свой комментарий
- Капитан может изменить статус
- В случае смены статуса у позиции, где менеджеры не запрашивали доработку, капитану необходимо обязательно указать комментарий для поставщика
- Когда капитан не выбрал ни одного комментария
- Ошибка
- Когда все менеджеры отработали позиции, по позициям нет доработок, капитан может сформировать рекомендации для руководителя и отправить на финальное согласование
- Капитан может решить, что какие-то позиции еще необходимо доработать со стороны поставщика
- Для этого необходимо сменить статус и указать комментарий, тогда запрос снова  уйдет на доработку поставщику
- В случае, если по какой-то позиции капитан рекомендует отклонение – комментарий отобразится у руководителя на финальном согласовании

## Действия Руководителя
- Интерфейс для руководителя
- Пока капитан не сформировал рекомендации – руководитель ожидает
- Чекбоксы и кнопки принятия конечного решения заблокированы, при наведении отображаются тултипы с пояснением
- На этом этапе руководителям доступен только просмотр дирекций/финкодов и позиций, чат так же доступен для просмотра и переговоров
- При переходе на уровень ниже - отображается список позиций в выбранном финкоде/дирекции по запросу
- Руководитель может отклонить позиции, либо согласовать их, когда ответственные менеджеры сделают свой выбор, в капитан сформирует рекомендации
- Если менеджеры отработали все позиции, а капитан сформировал рекомендации, токнопки для принятия решения у руководителя становятся активными
- На разводящей странице так же доступно принятие решения
- Если капитан порекомендовал “Отклонить” в той или иной позиции – отображается комментарий при наведении на иконку comment
- Согласовать выборочно: Для согласования с разводящей страницы необходимо нажать на кнопку “Согласовать” по кнопке или через чекбокс; Для согласования со страницы финкода/дирекции необходимо нажать на кнопку “Согласовать”
- Отклонить выборочно: Для отклонения с разводящей страницы необходимо нажать на кнопку “Отклонить”; Для отклонения со страницы финкода/дирекции необходимо нажать на кнопку “Отклонить”
- Согласовать все / Отклонить все: Все менеджеры отработали позиции; Руководителю доступны чекбоксы и все кнопки; Для массового согласования (отклонения) с разводящей страницы необходимо нажать на кнопку “Согласовать все” (“Отклонить все”)
- Для массового согласования (отклонения) через чекбокс необходимо выбрать все фин/дир и нажать на кнопку “Согласовать” (“Отклонить”) с каунтером, число в каунтере=количество выбранных чекбоксом позиций
- Модальное окно с подтверждением действия → Ошибка согласования / отклонения → Согласование (отклонение) успешно, отображение на разводящей странице
- На панели исчезают кнопки, отображается ФИО руководителя, принявшего фиальное решение по фин/дир
