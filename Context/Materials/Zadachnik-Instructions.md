Задачник
В разделе Задачник собраны задачи, которые назначены вам, а также задачи, созданные вами для себя или других пользователей. Раздел помогает контролировать текущую работу: видеть сроки, приоритет, автора задачи и отслеживать ее выполнение.
Вы можете:

* просматривать и изменять задачи и их статус;
* создавать задачи для себя или других сотрудников;
* настраивать автоматизации для регулярных задач;
* просматривать аналитику по задачам.

Как посмотреть список задач
Чтобы посмотреть список задач, перейдите в раздел Задачник.
В разделе есть вкладки:

* Задачи на меня — активные и завершенные задачи, в которых вы назначены исполнителем.
* Все задачи — все активные и завершенные задачи, доступные для просмотра.
* Автоматизация — правила автоматического создания задач по расписанию. Подробнее о работе с правилами.
* Дашборд — аналитика по задачам. Подробнее о просмотре аналитики.

Для каждой задачи отображаются:

* номер задачи;
* название задачи;
* статус задачи: Открыта — задача, которая еще не взята в работу, В работе — задача находится в работе, Завершена — задача завершена;
* ФИО сотрудника, который назначен исполнителем задачи. Отображается только на вкладке Все задачи;
* ФИО сотрудника, который создал задачу;
* срок выполнения. Рядом с просроченными задачами отображается значок;
* доступные действия с задачей: взять в работу, вернуть в открытые, завершить задачу. Отображается только на вкладке Задачи на меня. Подробнее о действиях с задачей.

Чтобы отображались только нужные задачи, примените фильтры.

Фильтры
Вы можете отфильтровать задачи по номеру, названию, статусу, создателю и исполнителю. По исполнителю можно отфильтровать только задачи на вкладке Все задачи. Для этого нажмите на название поля, введите или выберите значения из списка и нажмите Применить.
Также можно отфильтровать задачи с помощью переключателей в панели вверху:

* Задачи от руководителя — показать только задачи, которые руководитель назначил на вас. Отображается на вкладках Дашборд → Задачи на меня и Задачи на меня.
* Созданные мной — показать только задачи, которые создали вы. Отображается на вкладках Дашборд → Все задачи и Все задачи.
* Моя команда — показать только задачи, которые создали сотрудники вашей команды. Отображается на вкладках Задачи на меня и Все задачи.
* Просроченные задачи — показать только задачи с прошедшим сроком выполнения. Отображается только на вкладке Все задачи.
* Я наблюдатель — показать только задачи, в которых вы назначены наблюдателем. Отображается только на вкладке Все задачи.

Включите нужную опцию, чтобы отфильтровать задачи. Чтобы сбросить фильтры, нажмите Вернуть по умолчанию в панели справа.

Как создать задачи
Вы можете добавить задачи вручную или загрузить файл.

Вручную на портале:
1. Нажмите Создать задачу на вкладке Задачи на меня или Все задачи. Откроется окно Создание задачи.
2. Заполните поля:
   1. Заголовок задачи — название задачи.
   2. Описание — описание задачи. Необязательное поле.
   3. Приоритет — приоритет задачи. В зависимости от важности вы можете выбрать: Критичная, Важная, Обычная.
   4. Срок выполнения — дата, до которой задача должна быть завершена.
3. Отметьте сотрудников, на которых будет назначена задача, в блоке Исполнитель. Чтобы назначить задачу сразу на группу сотрудников, нажмите Добавить группу и укажите параметры поиска. Задача будет назначена на каждого из выбранных сотрудников. Вы можете выбрать до 50 исполнителей.
4. Если хотите добавить сотрудников, которым будет видна задача, отметьте их в блоке Наблюдатели. Включите опцию Видна всем, если хотите, чтобы задача отображалась для всех.
5. Если хотите, чтобы задача повторялась по определенному расписанию, включите опцию Включить и настроить в блоке Автоповтор. В открывшемся окне выберите настройки повтора и нажмите Сохранить. Подробнее о работе с автоповтором.
6. Нажмите Создать.

Как работать с задачами
Вы можете просматривать задачи, брать их в работу, изменять их, возвращать на доработку и завершать.

Просмотреть задачу
Чтобы посмотреть задачу, нажмите на нее. Справа откроется карточка с подробной информацией о задаче. В карточке есть вкладки:

* Детали — общая информация о задаче и вложения, если есть.
* Комментарии — чат с обсуждением задачи. Здесь можно сообщить о ходе выполнения или возникшей проблеме, посмотреть предыдущие сообщения и прикрепить файлы.
* История — информация об изменениях задачи.

Взять в работу
Взять задачу в работу можно любым из перечисленных способов:

* откройте карточку с задачей и нажмите В работу;
* на вкладке Задачи на меня в строке с нужной задачей нажмите значок в столбце Действия;
* на вкладке Задачи на меня отметьте задачи в первом столбце и нажмите В работу.

Статус задачи изменится на В работе.

Вернуть на доработку
Вы можете вернуть задачу на доработку, например, чтобы исполнитель доработал ее. Для этого используйте один из перечисленных способов:

* откройте карточку с задачей и нажмите Вернуть в «Открыта»;
* на вкладке Задачи на меня в строке с нужной задачей нажмите значок в столбце Действия;
* на вкладке Задачи на меня отметьте задачи в первом столбце и нажмите «Вернуть в Открыта».

Статус задачи изменится на Открыта.

Изменить задачу
Изменить можно только задачу в статусе Открыта или В работе, и где вы — создатель задачи.
Чтобы изменить задачу, нажмите на строку с задачей, в открывшемся окне нажмите Редактировать и измените данные.

Назначить на другого сотрудника
Вы можете назначить задачу на другого сотрудника, если вы — исполнитель задачи. Для этого:
1. Откройте карточку с задачей, в которой вы указаны исполнителем.
2. Нажмите Переназначить.
3. Выберите сотрудника, на которого хотите назначить задачу, и нажмите Переназначить.

Завершить задачу
Вы можете завершить задачу любым из перечисленных способов:

* откройте карточку с задачей и нажмите Завершить;
* на вкладке Задачи на меня в строке с нужной задачей нажмите значок в столбце Действия;
* на вкладке Задачи на меня отметьте задачи в первом столбце и нажмите Завершить.

Статус задачи изменится на Завершена.

Как работать с правилами автоповтора
Автоповтор позволяет автоматически создавать новые задачи:

* по расписанию — с указанной периодичностью;
* по событию — при наступлении события в продукте.

Чтобы добавить автоповтор, при создании задачи включите опцию Включить и настроить в блоке Автоповтор и задайте условия повторения.
Настроенные правила отображаются на вкладке Автоматизация. На вкладке отображаются только созданные вами задачи с настроенным автоповтором. Здесь можно:

* включить или отключить правило;
* изменить правило и указать новые параметры;
* удалить правило;
* найти нужное правило по названию в строке поиска вверху;
* показать только активные правила — для этого включите опцию Активные.
