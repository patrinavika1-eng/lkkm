Аналитика по задачам
В разделе Задачник на вкладке Дашборд отображается аналитика по вашим задачам и задачам сотрудников.
Чтобы создать новую задачу, в панели вверху нажмите Создать задачу. Подробнее о работе с задачами.

Как посмотреть аналитику по своим задачам
Нажмите вверху Задачи на меня. На дашборде вы увидите:

* Количество всех задач, задач в статусах Открыта и В работе, а также просроченных задач на текущий день. Нажмите на нужный статус, чтобы перейти к соответствующим задачам. Чтобы посмотреть все свои задачи независимо от статуса, нажмите Перейти ко всем задачам. Откроется вкладка Задачи на меня.
* Блок Производительность с графиком по количеству задач в каждом статусе. Нажмите Неделя, Месяц, Квартал, Период, чтобы посмотреть данные за нужный период.

Чтобы отобразить только задачи, назначенные руководителем, в панели вверху включите опцию Задачи от руководителя.

Как посмотреть аналитику по всем задачам
Нажмите вверху Все задачи. На дашборде вы увидите:

* Количество всех задач, задач в статусах Открыта и В работе, а также просроченных задач на текущий день. Нажмите на нужный статус, чтобы перейти к соответствующим задачам. Чтобы посмотреть все задачи независимо от статуса, нажмите Перейти ко всем задачам. Откроется вкладка Все задачи.
* Блок Аналитика по людям с количеством задач по каждому сотруднику. Данные можно отсортировать по количеству задач. Для этого нажмите на название столбца и выберите тип сортировки.
* Блок Производительность с графиком по количеству задач в каждом статусе. Нажмите Неделя, Месяц, Квартал, Период, чтобы посмотреть данные за нужный период.

Вы можете отфильтровать задачи. Для этого в панели вверху:

* включите опцию Созданные мной, чтобы увидеть задачи, созданные вами;
* включите опцию Моя команда, чтобы увидеть задачи сотрудников вашей команды. Фильтры заполнятся автоматически по данным вашего профиля. Вы можете изменить их, если нужно;
* введите ФИО сотрудника в поле поиска, чтобы посмотреть его задачи;
* нажмите Доп. фильтры, чтобы отфильтровать задачи по должности сотрудника, финкоду/дирекции или геозоне.

Чтобы сбросить фильтры, нажмите Вернуть по умолчанию.
