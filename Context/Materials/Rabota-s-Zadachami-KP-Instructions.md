# Коммерческие предложения: работа с задачами — документация (исходный текст)

адача — это отдельный товар из коммерческого предложения. В одном коммерческом предложении может быть несколько задач: они распределяются в зависимости от региона, торговой сети и категории товара. Чтобы завершить работу над коммерческим предложением, обработайте задачи, которые вам доступны.
В разделе Коммерческие предложения вы можете:

* посмотреть задачи;
* взять задачу в работу;
* назначить задачу на другого сотрудника;
* отправить задачу на доработку поставщику;
* принять или отклонить предложение поставщика.

Как посмотреть задачи
Чтобы посмотреть задачи в коммерческом предложении, перейдите на вкладку Активные КП и нажмите на строку с коммерческим предложением. Откроется раздел с задачами.
Для каждой задачи отображаются:

* № задачи — номер задачи.
* Статус — [статус](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/kommercheskie-predlozheniya/rabota-s-zadachami#%D1%81%D1%82%D0%B0%D1%82%D1%83%D1%81%D1%8B-%D0%B7%D0%B0%D0%B4%D0%B0%D1%87) работы категорийного менеджера с задачей.
* Статус логиста — [статус](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/kommercheskie-predlozheniya/rabota-s-zadachami#%D1%81%D1%82%D0%B0%D1%82%D1%83%D1%81%D1%8B-%D0%BB%D0%BE%D0%B3%D0%B8%D1%81%D1%82%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D1%85-%D1%83%D1%81%D0%BB%D0%BE%D0%B2%D0%B8%D0%B9) согласования логистических условий.
* ... — уменьшенное изображение товара.
* Наименование товара — название товара.
* SKU — код товара.
* ТС — название торговой сети.
* Геозона — геозона, к которой относится задача.
* Исполнитель — сотрудник, назначенный исполнителем задачи.
* Логист — сотрудник, ответственный за согласование логистических условий.

Для просмотра информации о задаче нажмите на нее. Подробнее в разделе [Описание карточки SKU](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/kommercheskie-predlozheniya/opisanie-kartochki-sku). Чтобы отображались только нужные задачи, примените [фильтры](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/kommercheskie-predlozheniya/rabota-s-zadachami#%D1%84%D0%B8%D0%BB%D1%8C%D1%82%D1%80%D1%8B).
Дополнительно вы можете посмотреть подробную информацию о поставщике и коммерческом предложении. Для этого справа вверху нажмите Смотреть подробную информацию о КП.
Вы можете [взять задачу в работу](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/kommercheskie-predlozheniya/rabota-s-zadachami#%D0%BA%D0%B0%D0%BA-%D0%B2%D0%B7%D1%8F%D1%82%D1%8C-%D0%B7%D0%B0%D0%B4%D0%B0%D1%87%D1%83-%D0%B2-%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D1%83), [перераспределить ее](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/kommercheskie-predlozheniya/rabota-s-zadachami#%D0%BA%D0%B0%D0%BA-%D0%BD%D0%B0%D0%B7%D0%BD%D0%B0%D1%87%D0%B8%D1%82%D1%8C-%D0%B7%D0%B0%D0%B4%D0%B0%D1%87%D1%83-%D0%BD%D0%B0-%D0%B4%D1%80%D1%83%D0%B3%D0%BE%D0%B3%D0%BE-%D1%81%D0%BE%D1%82%D1%80%D1%83%D0%B4%D0%BD%D0%B8%D0%BA%D0%B0) на другого сотрудника, [отправить на доработку](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/kommercheskie-predlozheniya/rabota-s-zadachami#%D0%BA%D0%B0%D0%BA-%D0%BE%D1%82%D0%BF%D1%80%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D0%B7%D0%B0%D0%B4%D0%B0%D1%87%D1%83-%D0%BD%D0%B0-%D0%B4%D0%BE%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D1%83) поставщику, а также [принять](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/kommercheskie-predlozheniya/rabota-s-zadachami#%D0%BA%D0%B0%D0%BA-%D0%BF%D1%80%D0%B8%D0%BD%D1%8F%D1%82%D1%8C-%D0%BF%D1%80%D0%B5%D0%B4%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5) или [отклонить](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/kommercheskie-predlozheniya/rabota-s-zadachami#%D0%BA%D0%B0%D0%BA-%D0%BE%D1%82%D0%BA%D0%BB%D0%BE%D0%BD%D0%B8%D1%82%D1%8C-%D0%BF%D1%80%D0%B5%D0%B4%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5) предложение поставщика. Действия доступны только для задач из вашей зоны ответственности. Если задача не относится к вашей зоне ответственности, строка подсвечивается серым и действия с ней недоступны.
Статусы задач

* Новое — новая задача.
* В работе — задача находится в работе у категорийного менеджера.
* Требует доработки — категорийный менеджер отправил задачу поставщику на доработку.
* Принято — категорийный менеджер принял предложение поставщика.
* Отклонено — категорийный менеджер отклонил предложение поставщика.

Статусы логистических условий

* Нет решения — логист еще не принял нерешние по логистическим условиям.
* В работе — логистические условия находятся в работе у логиста.
* Требует доработки — логист отправил условия поставщику на доработку.
* Согласовано — логист согласовал логистические условия.
* Отклонено — логист отклонил логистические условия.

Фильтры
Чтобы показать только задачи из вашей зоны ответственности, включите опцию Только моя зона.
Чтобы показать задачи по выбранным параметрам, нажмите на строку с названием фильтра и отметьте нужные значения. Вы можете отметить сразу несколько значений. Доступные фильтры: Статус, Геозона, ТС.
Как взять задачу в работу
Вы можете взять в работу одну или несколько задач из вашей зоны ответственности.
Для этого:

1. Отметьте одну или несколько строк с задачами.Чтобы отметить все доступные задачи из вашей зоны ответственности, нажмите в первом столбце вверху таблицы.
2. В открывшейся панели нажмите Назначить на себя.

Одну задачу также можно взять в работу из карточки SKU. Для этого нажмите на строку с задачей и на вкладке Основная информация нажмите Взять в работу.
Статус задач изменится на В работе, а вы назначитесь исполнителем.
Как назначить задачу на другого сотрудника
Вы можете назначить одну или несколько задач другому сотруднику, если он работает в соответствующей зоне ответственности.
Для этого:

1. Отметьте одну или несколько строк с задачами.Чтобы отметить все доступные задачи из вашей зоны ответственности, нажмите в первом столбце вверху таблицы.
2. В открывшейся панели нажмите Перераспределить.
3. Выберите, кому назначить задачи: Сотруднику или Моему руководителю.
4. Если выбрали Сотруднику, выберите сотрудника из списка.
5. Нажмите Перераспределить.

Одну задачу также можно перераспределить из карточки SKU. Для этого откройте задачу и на вкладке Основная информация нажмите Перераспределить.
Задачи будут назначены выбранному сотруднику.
Как отправить задачу на доработку
Если для принятия решения нужна дополнительная информация или документы от поставщика, отправьте одну или несколько задач на доработку.
Для этого:

1. Отметьте одну или несколько строк с задачами. Чтобы отметить все доступные задачи из вашей зоны ответственности, нажмите в первом столбце вверху таблицы.
2. В открывшейся панели нажмите На доработку.
3. Укажите, что поставщику нужно уточнить или изменить.
4. Нажмите Отправить.

Одну задачу также можно отправить на доработку из карточки SKU. Для этого откройте задачу и на вкладке Основная информация нажмите На доработку поставщику.
Статус задач изменится на Требует доработки. После ответа поставщика задачи можно вернуть в работу.
Как отклонить предложение
Если предложение поставщика вас не устраивает, отклоните одну или несколько задач из вашей зоны ответственности.
Для этого:

1. Отметьте одну или несколько строк с задачами.Чтобы отметить все доступные задачи из вашей зоны ответственности, нажмите в первом столбце вверху таблицы.
2. В открывшейся панели нажмите Отклонить. Откроется окно с подготовленным текстом письма поставщику.
3. Измените текст письма, если необходимо.
4. Выберите причину в поле Причина отказа. Если выбрали Другое, укажите свою причину.
5. Нажмите Отклонить.

Одну задачу также можно отклонить из карточки SKU. Для этого откройте задачу и на вкладке Основная информация нажмите Отклонить.
Чтобы отклонить сразу все доступные задачи из вашей зоны ответственности, нажмите Отклонить в моей зоне справа внизу. Предварительно отмечать задачи не нужно.
Статус отклоненных задач изменится на Отклонено
Как принять предложение
Если предложение поставщика вас устраивает, примите одну или несколько задач из вашей зоны ответственности.
Для этого:

1. Отметьте одну или несколько строк с задачами.Чтобы отметить все доступные задачи из вашей зоны ответственности, нажмите в первом столбце вверху таблицы.
2. В открывшейся панели нажмите Принять. Откроется окно с подготовленным текстом письма поставщику.
3. Измените текст письма, если необходимо.
4. Нажмите Отправить.

Одну задачу также можно принять из карточки SKU. Для этого откройте задачу и на вкладке Основная информация нажмите Принять.
Чтобы принять сразу все доступные задачи из вашей зоны ответственности, нажмите Принять в моей зоне справа внизу. Предварительно отмечать задачи не нужно.
Статус принятых задач изменится на Принято.
