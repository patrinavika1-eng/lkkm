Работа с договоренностями
Договоренности — это документы, в которых фиксируются согласованные с поставщиком условия сотрудничества. На портале есть два типа договоренностей:

* Протокол — документ с договоренностями. Доступен для просмотра поставщику, нельзя изменять после создания;
* Прочее — внутренние записи или заметки о договоренностях. Доступны только автору, можно изменять после создания.

В разделе Договоренности вы можете:

* посмотреть договоренности;
* добавить договоренность;
* изменить договоренность.

Как посмотреть договоренности
Чтобы посмотреть договоренности, перейдите в раздел Договоренности. Слева отображается меню, где договоренности сгруппированы по типу: Все, Протоколы и Прочее. Выберите нужный тип, чтобы отфильтровать список. Центральная часть разделена на две области: слева — список договоренностей, справа — область предварительного просмотра выбранной договоренности.
Каждая договоренность отмечена цветом в зависимости от ее типа: — протокол, — прочее. Нажмите на договоренность, чтобы посмотреть ее содержимое.
Для каждой договоренности отображаются:

* дата создания или последнего изменения;
* название поставщика;
* название договоренности;
* текст договоренности;
* отметка важности ;
* вложенные файлы, если есть;
* статус, если договоренность типа Протокол. Возможные статусы: Просмотрено поставщиком и Не просмотрено поставщиком.

Чтобы найти договоренность или настроить отображение, используйте [инструменты поиска](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/notes#%D0%B8%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BC%D0%B5%D0%BD%D1%82%D1%8B-%D0%BF%D0%BE%D0%B8%D1%81%D0%BA%D0%B0).
Как добавить договоренность
Вы можете добавить договоренность типа Протокол или Прочее. Обратите внимание, что вы не сможете изменить тип договоренности после создания.
Прочее
Протокол
Договоренности типа Прочее доступны только автору и их можно изменять после создания.
Чтобы добавить рабочую заметку:

1. Нажмите Добавить. Справа откроется окно Новая договоренность.
2. Выберите тип Прочее.
3. Включите опцию Важная, если хотите выделить договоренность среди остальных.
4. Заполните обязательные поля:
   * Поставщик — название поставщика.
   * Заголовок — название договоренности.
   * Текст — информация по договоренности.
Если текст договоренности есть в бумажном документе или на изображении, вы можете распознать его автоматически. Для этого нажмите OCR — Распознавания документов, в открывшемся окне загрузите файл и скопируйте распознанный текст.
5. Прикрепите файлы к договоренности, если нужно. Для этого перетащите их в область Прикрепите файлы: или выберите на компьютере.
6. Нажмите Добавить.

После создания вы можете [изменить договоренность](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/notes#%D0%BA%D0%B0%D0%BA-%D0%B8%D0%B7%D0%BC%D0%B5%D0%BD%D0%B8%D1%82%D1%8C-%D0%B4%D0%BE%D0%B3%D0%BE%D0%B2%D0%BE%D1%80%D0%B5%D0%BD%D0%BD%D0%BE%D1%81%D1%82%D1%8C).



Как изменить договоренность
Вы можете изменять данные в договоренностях типа Прочее. Для этого:

1. Нажмите на плитку с договоренностью.
2. Нажмите справа вверху.
3. Измените данные в договоренности. Вы можете изменить все данные в договоренности, кроме ее типа.
4. Нажмите Сохранить.

Инструменты поиска
Чтобы найти договоренность, введите название или часть текста из договоренности в поле Поиск.
Вы можете отфильтровать данные по:

* поставщикам. Для этого нажмите на поле Поставщик и введите или выберите значения из списка;
* по дате создания. Для этого нажмите:
   * — сначала новые договоренности;
   * — сначала более ранние договоренности;
* по важности. Для этого включите опцию Важная.
