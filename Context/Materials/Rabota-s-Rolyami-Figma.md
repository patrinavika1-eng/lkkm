## Общее поведение
- При загрузке страницы автоматически выбирается первый активный ИС и первый раздел в нём. Колонка ролей отображает все роли с их текущими настройками для этого раздела.
- При переключении раздела колонка ролей обновляется и показывает настройки доступа специфичные для выбранного раздела. Настройки каждой роли хранятся отдельно для каждой связки ИС + Раздел — то есть у Директора в «Договорённостях» могут быть одни права, а в «Матрице ответственных» — другие. Зелёная галочка у роли означает что для данного раздела настроен хотя бы один атрибут
- При нажатии на строки ролей - они раскрываются
- Документация к компоненту
- При включении свитча “Показывать неактивные” отображаются неактивные ИС, разделы и роли внизу списков
- Если ИС и Раздел состоят только из неактивных сущностей, но не отображаем разделитель

## Добавление ИС
- Для добавления ИС необходимо нажать на кнопку добавления
- В появившемся модальном окне необходимо заполнить данные
- Пример заполненных данных
- Ошибка
- После успешного добавления ИС она автоматически выбирается.  Колонка разделов показывает пустое состояние с кнопкой "Добавить раздел" — чтобы сразу направить пользователя к следующему шагу

## Добавление РАЗДЕЛА
- Для добавления раздела в ИС необходимо нажать на кнопку в заглушке (если разделов еще нет)
- Или через шапку колонки раздела, если к существующим разделам необходимо добавить новые
- В появившемся модальном окне необходимо заполнить данные
- Пример заполненных данных
- Типы процессов: – Коммерческие предложени – Ценовые Спецификации – PLU
- Ошибка
- После создания раздел автоматически выбирается и выделяется первым в списке

## Добавление РОЛИ
- Для добавления роли необходимо нажать на кнопку добавления
- В появившемся модальном окне необходимо заполнить данные
- Пример заполненных данных
- Ошибка
- После создания роль появляется в списке и становится доступной для настройки во всех ИС и разделах.

## Настройка РОЛИ
- Для настройки роли необходимо кликнуть по ней и в открывшемся аккордеоне настроить права доступа
- Доступы настраиваются отдельно для каждой роли.  Тогл включает доступ целиком — если операция выключена, атрибуты не показываются.  Ддля каждого атрибута выбирается область доступа: Свои, Все или Нет
- При включении по умолчанию включаем “Свои”
- После необходимых настроек пользователю надо сохранить конфигурации, либо отменить – сбросить до предыдущего значения
- Ошибка
- Успех
- У роли отобразилась зеленая галочка - признак того, что роль для ИС>Раздела настроена
- Любое изменение настроек роли будет инициировать появление кнопок отмены и сохранения изменений

## Редактирование ИС, раздела и роли
Макеты без текстовых пояснений: «Edit IS» → модальное окно → ошибка → готово; то же для раздела («Edit Part») и роли («Edit Role»).
