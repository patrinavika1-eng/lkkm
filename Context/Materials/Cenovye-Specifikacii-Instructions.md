## Работа с запросами

Запрос на ценовую спецификацию — это запрос поставщика на изменение условий по одному или нескольким товарам, например цены, НДС, кванта поставки или региона продаж. Каждый товар в запросе представлен отдельной позицией. В запросе позиции объединены по дирекциям/финкодам и распределены между сотрудниками, которые участвуют в согласовании.
Согласование запроса проходит в несколько этапов:

1. Категорийный менеджер рассматривает доступные ему позиции и принимает решение: согласовать, отклонить или запросить доработку у поставщика. Подробнее см. [Работа с позициями для КМ](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/cenovye-specifikacii/rabota-s-poziciyami-zaprosa/rabota-s-poziciyami-dlya-km).
2. Капитан проверяет решения менеджеров. Если нужна доработка, он формирует сводку и отправляет ее поставщику. Если доработка не требуется, капитан формирует рекомендации для руководителя. Подробнее см. [Работа с позициями для капитана](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/cenovye-specifikacii/rabota-s-poziciyami-zaprosa/rabota-s-poziciyami-dlya-kapitana).
3. Руководитель рассматривает рекомендации капитана и принимает финальное решение. Подробнее см. [Работа с позициями для руководителя](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/cenovye-specifikacii/rabota-s-poziciyami-zaprosa/rabota-s-poziciyami-dlya-rukovoditelya).

После финального согласования по принятым позициям автоматически формируется каталог цен (КЦ) и отправляется в ТОРГ ERP. Далее КЦ проходит этапы обработки до активации в системе.
В разделе Ценовые спецификации вы можете:

* посмотреть запросы и их статусы;
* посмотреть и обработать позиции внутри запроса;
* посмотреть подробную информацию и ход согласования запроса;
* посмотреть историю действий.

Как посмотреть запросы
Чтобы посмотреть активные запросы, перейдите на вкладку Активные запросы. Здесь отображаются новые запросы и запросы, по которым еще идет работа. Подробнее см. [Статусы запросов](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/cenovye-specifikacii/rabota-s-zaprosami#%D1%81%D1%82%D0%B0%D1%82%D1%83%D1%81%D1%8B-%D0%B7%D0%B0%D0%BF%D1%80%D0%BE%D1%81%D0%BE%D0%B2).
Чтобы посмотреть завершенные запросы, перейдите на вкладку Архив. Здесь отображаются обработанные запросы, по которым принято итоговое решение.
Для каждого запроса указаны:

* № запроса — номер запроса;
* Статус запроса — текущий этап обработки запроса. Подробнее см. [Статусы запросов](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/cenovye-specifikacii/rabota-s-zaprosami#%D1%81%D1%82%D0%B0%D1%82%D1%83%D1%81%D1%8B-%D0%B7%D0%B0%D0%BF%D1%80%D0%BE%D1%81%D0%BE%D0%B2);
* Статус КЦ — текущий статус каталога цен в ТОРГ ERP. Каталог цен формируется автоматически после внутреннего согласования запроса, а статус показывает путь документа до активации в системе. Подробнее см. [Статусы КЦ](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/cenovye-specifikacii/rabota-s-zaprosami#%D1%81%D1%82%D0%B0%D1%82%D1%83%D1%81%D1%8B-%D0%BA%D1%86);
* Тип запроса — изменение, которое запросил поставщик. Возможные варианты: Повышение цены, Изменение кванта поставки, Добавление региона поставки.
* Торговые сети — торговые сети, к которым относится запрос;
* Финкод/Дирекция — финкод или дирекция, к которым относится запрос;
* Геозоны X5 — геозоны, к которым относится запрос;
* Ценовой сегмент — ценовой сегмент, к которому относится запрос;
* Поставщик — наименование поставщика;
* Дата подачи — дата отправки запроса поставщиком.

Чтобы посмотреть позиции, которые входят в запрос, нажмите на строку с запросом. Откроется карточка запроса. Подробнее см. [Работа с позициями запроса](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/cenovye-specifikacii/rabota-s-poziciyami-zaprosa) и [Описание карточки запроса](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/cenovye-specifikacii/opisanie-kartochki-zaprosa).
Чтобы отображались только нужные запросы, примените [фильтры](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/start/instrumenty-nastroyki-tablicy#%D1%84%D0%B8%D0%BB%D1%8C%D1%82%D1%80%D0%B0%D1%86%D0%B8%D1%8F). Включите опцию:

* Запросы для отработки, чтобы показать запросы, доступные для отработки;
* Требует внимания, чтобы показать запросы, которые после согласования были отправлены в ТОРГ ERP и вернулись с ошибкой.

Вы также можете [отсортировать ](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/start/instrumenty-nastroyki-tablicy#%D1%81%D0%BE%D1%80%D1%82%D0%B8%D1%80%D0%BE%D0%B2%D0%BA%D0%B0)запросы в порядке возрастания или убывания. Чтобы скачать данные из таблицы, нажмите Скачать Excel.
Статусы запросов

* Новое — по запросу еще не принято решений.
* Требует доработки — хотя бы одна позиция отправлена поставщику на доработку.
* В работе — по части позиций уже принято решение, но работа с запросом еще не завершена.
* Принято — по запросу принято итоговое положительное решение.
* Отклонено — по запросу принято итоговое отрицательное решение.

Статусы КЦ
Чтобы посмотреть этапы обработки каталога цен, нажмите на его статус. Справа откроется панель с историей изменений. Для статусов Ожидает согласования и Не сформирован подробная информация недоступна.

* Ожидает согласования — внутреннее согласование запроса еще не завершено, каталог цен не сформирован.
* Отправлено в ТОРГ — каталог цен отправлен в ТОРГ ERP.
* Есть ошибка — при обработке каталога цен возникла ошибка.
* Истек срок действия — срок действия каталога цен истек.
* На подписании поставщиком — каталог цен передан поставщику на подписание.
* Подписано поставщиком — поставщик подписал каталог цен.
* Активирован КЦ и прогружен в систему — каталог цен активирован и загружен в систему.
* Не сформирован — каталог цен не сформирован, так как запрос был отклонен.

## Работа с позициями для КМ

Категорийный менеджер рассматривает позиции из своей зоны ответственности и принимает по ним решение: согласовать, отклонить или запросить доработку у поставщика.
Как посмотреть позиции
Откройте нужный запрос и перейдите на вкладку Позиции. Здесь отображаются доступные вам дирекции/финкоды и прогресс обработки позиций. Подробнее см. [Описание карточки запроса](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/cenovye-specifikacii/opisanie-kartochki-zaprosa).
Чтобы посмотреть входящие позиции, нажмите на строку, Отработать или стрелку справа. Откроется список позиций с данными о товарах и изменениях, которые запросил поставщик.
Статусы позиций
Статус показывает текущее решение по позиции:
   * Новое — позиция еще не обработана.
   * Согласовано — позиция согласована.
   * Отклонено — позиция отклонена.
Если вы запросили доработку, рядом с позицией отображается информация о запросе и ваш комментарий.
Как согласовать позиции
Вы можете согласовать позиции на уровне дирекции/финкода либо выбрать отдельные позиции внутри них.
Чтобы согласовать позиции по одному или нескольким дирекциям/финкодам:
   1. Отметьте нужные строки.
   2. Нажмите Согласовать.
   3. Проверьте выбранные позиции и нажмите Согласовать.
Чтобы согласовать отдельные позиции:
   1. Откройте нужную дирекцию/финкод.
   2. Отметьте одну или несколько строк.
   3. Нажмите Согласовать.
   4. Проверьте выбранные позиции и нажмите Согласовать.
Чтобы согласовать сразу все доступные позиции запроса, не выбирайте строки и нажмите Согласовать все.
Статус обработанных позиций изменится на Согласовано, а прогресс обработки обновится.
Как отклонить позиции
Вы можете отклонить позиции на уровне дирекции/финкода либо выбрать отдельные позиции внутри них.
Чтобы отклонить позиции по одному или нескольким дирекциям/финкодам:
   1. Отметьте нужные строки.
   2. Нажмите Отклонить.
   3. Укажите причину отклонения и нажмите Отклонить.
Чтобы отклонить отдельные позиции:
   1. Откройте нужную дирекцию/финкод.
   2. Отметьте одну или несколько строк.
   3. Нажмите Отклонить.
   4. Укажите причину отклонения и нажмите Отклонить.
Чтобы отклонить сразу все доступные позиции запроса, не выбирайте строки и нажмите Отклонить все.
Статус обработанных позиций изменится на Отклонено, а прогресс обработки обновится.
Как отправить позиции на доработку
Если для принятия решения нужна дополнительная информация или поставщику необходимо изменить данные, отправьте позиции на доработку. Вы можете отправить на доработку позиции на уровне дирекции/финкода либо выбрать отдельные позиции внутри них.
Чтобы отправить на доработку позиции по одному или нескольким дирекциям/финкодам:
   1. Отметьте нужные строки.
   2. Нажмите Запросить доработку.
   3. Укажите, что поставщику необходимо изменить или уточнить, и нажмите Отправить.
Чтобы запросить доработку отдельных позиций:
   1. Откройте нужную дирекцию/финкод.
   2. Отметьте одну или несколько строк.
   3. Нажмите Запросить доработку.
   4. Укажите, что поставщику необходимо изменить или уточнить, и нажмите Отправить.
Чтобы запросить доработку по всем доступным позициям, не выбирайте строки и нажмите Запросить доработку.
Капитан увидит запрос на доработку и комментарий при формировании сводки для поставщика.

## Работа с позициями для капитана

Капитан проверяет решения категорийных менеджеров и обрабатывает позиции из своей зоны ответственности, если нужно. После этого он [отправляет позиции поставщику на доработку](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/cenovye-specifikacii/rabota-s-poziciyami-zaprosa/rabota-s-poziciyami-dlya-kapitana#%D0%BA%D0%B0%D0%BA-%D0%BE%D1%82%D0%BF%D1%80%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D0%BF%D0%BE%D0%B7%D0%B8%D1%86%D0%B8%D0%B8-%D0%BF%D0%BE%D1%81%D1%82%D0%B0%D0%B2%D1%89%D0%B8%D0%BA%D1%83-%D0%BD%D0%B0-%D0%B4%D0%BE%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D1%83) или [формирует рекомендации для руководителя](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/cenovye-specifikacii/rabota-s-poziciyami-zaprosa/rabota-s-poziciyami-dlya-kapitana#%D0%BA%D0%B0%D0%BA-%D1%81%D1%84%D0%BE%D1%80%D0%BC%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D1%82%D1%8C-%D1%80%D0%B5%D0%BA%D0%BE%D0%BC%D0%B5%D0%BD%D0%B4%D0%B0%D1%86%D0%B8%D0%B8-%D1%80%D1%83%D0%BA%D0%BE%D0%B2%D0%BE%D0%B4%D0%B8%D1%82%D0%B5%D0%BB%D1%8E).
Если вам назначены позиции для обработки, согласуйте, отклоните их или запросите доработку. Подробнее см. [Работа с позициями для КМ](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/cenovye-specifikacii/rabota-s-poziciyami-zaprosa/rabota-s-poziciyami-dlya-km).
Как посмотреть позиции
Откройте нужный запрос и перейдите на вкладку Позиции. Здесь отображаются дирекции/финкоды, прогресс обработки и решения КМ. Подробнее см. [Описание карточки запроса](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/cenovye-specifikacii/opisanie-kartochki-zaprosa).В столбце Согласование менеджеров можно посмотреть результаты обработки позиций по каждой дирекции/финкоду.
Чтобы посмотреть позиции, нажмите на нужную строку или стрелку справа. Для просмотра и изменения решений по позициям нажмите Сводка решений.
Статусы обработки
Для каждой дирекции/финкода отображается текущий этап обработки:
   * Нет решений — категорийные менеджеры еще не завершили обработку позиций;
   * Готово к финалу — позиции обработаны, доработка поставщиком не требуется. Можно сформировать рекомендации для руководителя;
   * Требует доработки — по одной или нескольким позициям требуется доработка у поставщика;
   * На доработке — позиции отправлены поставщику;
   * У руководителя — рекомендации отправлены руководителю для финального согласования.
Как отправить позиции поставщику на доработку
Если хотя бы один КМ запросил доработку, после обработки позиций сформируйте сводку для поставщика. В окне Сводка решений можно проверить решения КМ, выбрать комментарии для поставщика и при необходимости изменить решение по позиции. Если вы сами укажете для позиции Требует доработки, добавьте комментарий с причиной.
Чтобы отправить позиции на доработку:
   1. Нажмите Сводка решений.
   2. Проверьте решения категорийных менеджеров по позициям.
   3. Измените решение по позиции на Требует доработки, если необходимо.
   4. Выберите комментарии категорийных менеджеров, которые нужно передать поставщику.
   5. При необходимости отметьте Добавить свой комментарий и введите текст.
   6. Нажмите Отправить поставщику.
После отправки статус обработки изменится на На доработке. Дождитесь, когда поставщик внесет изменения и запрос снова вернется в работу.
Как сформировать рекомендации руководителю
Если КМ обработали позиции и доработка поставщиком не требуется, сформируйте рекомендации для руководителя. В окне Сводке решений можно оставить решения КМ без изменений или изменить рекомендацию по отдельной позиции.
Для этого:
   1. Нажмите Сводка решений.
   2. Проверьте решения категорийных менеджеров по позициям.
   3. Измените решение по позиции на Согласовано или Отклонено, если необходимо.
   4. При необходимости отметьте Добавить свой комментарий и введите текст.
   5. Нажмите Отправить руководителю.
Если по позиции рекомендовано отклонение, комментарий капитана будет доступен руководителю при финальном согласовании. После отправки статус обработки изменится на У руководителя.

## Работа с позициями для руководителя

Руководитель рассматривает рекомендации капитана и принимает финальное решение по позициям после завершения предыдущих этапов согласования. До этого позиции можно просматривать, но согласование и отклонение недоступны.
Как посмотреть позиции
Откройте нужный запрос и перейдите на вкладку Позиции. Здесь отображаются дирекции/финкоды и рекомендации капитана. Подробнее см. [Описание карточки запроса](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/cenovye-specifikacii/opisanie-kartochki-zaprosa).
В столбце Рекомендации капитана можно посмотреть результаты по позициям. Пока предыдущие этапы согласования не завершены, действия для принятия финального решения недоступны.
Чтобы посмотреть позиции, нажмите на строку или стрелку справа. Откроется список позиций с рекомендациями капитана. Если капитан добавил комментарий к позиции, наведите на значок , чтобы посмотреть его.
Рекомендации капитана
Для каждой позиции отображается рекомендация капитана:
   * Согласовано — капитан рекомендует согласовать позицию;
   * Отклонено — капитан рекомендует отклонить позицию.
Как согласовать позиции
Вы можете согласовать позиции запроса по одной или нескольким дирекциям/финкодам, отдельные позиции внутри них или сразу все доступные позиции.
Чтобы согласовать позиции запроса по одной дирекции/финкоду, нажмите Согласовать в соответствующей строке и подтвердите решение.
Чтобы согласовать позиции по нескольким дирекциям/финкодам:
   1. Отметьте нужные строки.
   2. Нажмите Согласовать.
   3. Проверьте выбранные позиции и нажмите Согласовать и отправить.
Чтобы согласовать отдельные позиции:
   1. Откройте нужную дирекцию/финкод.
   2. Отметьте одну или несколько строк.
   3. Нажмите Согласовать.
   4. Проверьте выбранные позиции и нажмите Согласовать и отправить.
Чтобы согласовать все доступные позиции запроса, не выбирайте строки и нажмите Согласовать все.
В столбце Финальное решение отобразится Согласовано. По согласованным позициям формируется каталог цен и отправляется в ТОРГ ERP.
Как отклонить позиции
Вы можете отклонить позиции запроса по одной или нескольким дирекциям/финкодам, отдельные позиции внутри них или сразу все доступные позиции.
Чтобы отклонить позиции запроса по одной дирекции/финкоду, нажмите Отклонить в соответствующей строке и подтвердите решение.
Чтобы отклонить позиции по нескольким дирекциям/финкодам:
   1. Отметьте нужные строки.
   2. Нажмите Отклонить.
   3. Укажите причину отклонения и нажмите Отклонить.
Чтобы отклонить отдельные позиции:
   1. Откройте нужную дирекцию/финкод.
   2. Отметьте одну или несколько строк.
   3. Нажмите Отклонить.
   4. Укажите причину отклонения и нажмите Отклонить.
Чтобы отклонить все доступные позиции запроса, не выбирайте строки и нажмите Отклонить все.
В столбце Финальное решение отобразится Отклонено.

## Описание карточки запроса

В карточке запроса можно посмотреть информацию для принятия решения, позиции запроса и ход их согласования. Чтобы открыть карточку, нажмите на строку нужного запроса в разделе Ценовые спецификации. В верхней части карточки отображаются номер, дата запроса, поставщик, тип и текущий статус запроса.
В карточке доступны:
   * позиции запроса, действия с ними и результаты их обработки — на вкладке Позиции;
   * данные, которые поставщик указал при создании запроса — на вкладке Детали запроса;
   * ход согласования и решения участников — на вкладке Лист согласования;
   * аналитические данные по запросу — на вкладке Аналитика.
Как посмотреть позиции
Чтобы посмотреть позиции из запроса, перейдите на вкладку Позиции. Позиции сгруппированы по дирекциям/финкодам. Здесь отображаются прогресс обработки и решения по позициям.
Доступные данные и действия зависят от вашей роли:
   * если вы КМ — подробнее см. [Работа с позициями для КМ](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/cenovye-specifikacii/rabota-s-poziciyami-zaprosa/rabota-s-poziciyami-dlya-km);
   * если вы капитан — подробнее см. [Работа с позициями для капитана](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/cenovye-specifikacii/rabota-s-poziciyami-zaprosa/rabota-s-poziciyami-dlya-kapitana);
   * если вы руководитель — подробнее см. [Работа с позициями для руководителя](https://instructions.x5.ru/lkkm-manager/lichnyy-kabinet-kategoriynogo-menedzhera/cenovye-specifikacii/rabota-s-poziciyami-zaprosa/rabota-s-poziciyami-dlya-rukovoditelya).
Как посмотреть ход согласования
Чтобы посмотреть, как проходит согласование позиций, перейдите на вкладку Лист согласования.
Для каждой позиции отображаются дирекция/финкод, товар, участники согласования и время обработки. Рядом с ФИО участника отображается статус его решения:
   * — согласовано;
   * — отклонено;
   * — пока нет решения;
   * — запрошена доработка;
   * — ожидает решения менеджеров.
Наведите на ФИО участника, чтобы посмотреть его электронную почту и скопировать адрес.
Чтобы посмотреть только нужные позиции, используйте фильтры:
   * Только мои — показать позиции, которые относятся к вашей зоне ответственности;
   * Есть отклонения — показать позиции, по которым есть отклонение менеджера;
   * Ожидает менеджеров — показать позиции, по которым менеджеры еще не приняли решение.
Можно включить несколько фильтров одновременно. Чтобы отменить фильтрацию, нажмите Сбросить фильтры.
Также можно отфильтровать позиции по значениям в отдельных столбцах. Для этого нажмите на название столбца и выберите значения для фильтрации.
