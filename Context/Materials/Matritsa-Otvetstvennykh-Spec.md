Навигация
Чтобы попасть в раздел, необходимо из сайдбарменю перейти в пункт «Матрица ответственных».
На странице отображается:
- таблица сотрудников,
- настройки колонок,
- фильтрация,
- кнопка запроса расширенного доступа.

1. Таблица сотрудников
Ограничение на строку - 1 строка
Все, что не вмещается - прячется под троеточием
По наведению на скрытый текст в тултипе отображаем полный текст

1.1. Настройка колонок
По нажатию на кнопку «Настройки таблицы» открывается модальное окно. Доступны 11 колонок.
Функциональность:
- включение/выключение отображения колонок;
- изменение порядка колонок (драг энд дроп);
- сброс настроек до дефолтных 11 колонок;
- кнопки «Отменить» и «Применить»;
- если выбраны все 11 колонок, при наведении на иконку-глазик показываем тултип «Достигнут лимит видимых колонок».

1.2. Фильтрация
По нажатию на кнопку «Фильтрация» открывается панель с фильтрами.
Доступно 6 колонок для фильтрации по умолчанию:
- ФИО сотрудника
- Должность
- Департамент
- Торговая сеть
- Геозона
- Основной финансовый код

Логика:
- используется коллектор фильтров с логикой «содержит»;
- можно вводить значения вручную;
- только для «Основной ФК» доступен выбор типа поиска: по наименованию или по коду;
- кнопки: «Применить», «Сбросить фильтры»;
- количество активных фильтров отображается в счётчике на кнопке после применения фильтров.

Кнопка «Сбросить фильтры» обнуляет фильтры до дефолтного состояния, таблица возвращается в исходное состояние без дополнительного нажатия «Применить».
Если по фильтрам ничего не найдено:
- показывается информер «Ничего не найдено. Измените или сбросьте фильтры, чтобы увидеть данные» + кнопка «Сбросить фильтры»;
- виден только хедер таблицы и пагинация.

1.3. Сортировка
Сортировка доступна в колонке «ФИО сотрудника».
Стандартное поведение:
- дефолт: иконка «sort off»;
- 1-й клик — сортировка по возрастанию;
- 2-й клик — по убыванию;
- 3-й — сброс.
Правила:
- строки сортируются по алфавиту А→Я / Я→А;
- даты: новые→старые и наоборот;
- числа: по возрастанию/убыванию.

1.4. Поведение строк
- при наведении строка подсвечивается состоянием hover;
- в последней колонке — иконки-карандаши:
  - активны только для администраторов, имеющих право редактировать выбранного сотрудника;
  - если пользователь — админ, но он не может редактировать конкретного сотрудника, иконка неактивна + тултип: «Редактировать может администратор данного департамента или суперпользователь»;
  - у рядовых сотрудников панель действий полностью скрыта;
  - напротив ФИО может отображаться звёздочка — значит сотрудник является администратором.
Клики:
- клик по строке открывает карточку сотрудника;
- клик по карандашу — сразу открывает сайдбар редактирования.

2. Карточка сотрудника

2.1. Структура
В карточке отображаются:
- хлебные крошки (возврат в таблицу);
- ФИО и статус.

Страница разделена на два блока:

Верхний блок
- ФИО
- должность
- табельный номер
- почта
- дерево подразделений
- информация: является ли капитаном, капитан каких ФК, капитан каких поставщиков

Нижний блок — табы зон ответственности
- категории
- основные ФК
- УИ-3, УИ-4
- временные ФК + период действия
- территория и регионы
- ценовые сегменты
- поставщики и вендоры
- комментарий

Информация статична и меняется только после редактирования.

Кнопка редактирования
- фиксирована в нижней части страницы;
- доступна только если пользователь имеет право редактировать сотрудника.

3. Редактирование сотрудника

После нажатия на «Редактировать» открывается сайдпейдж c атрибутами:
Доступные параметры:
- капитан
- капитан ФК
- капитан поставщика
- постоянные ФК
- УИ-3
- УИ-4
- временный ФК
- период действия временного ФК
- поставщики
- геозоны
- комментарий

3.1. Логика и валидации
Последовательность
- нельзя выбрать капитана ФК, пока не выбран капитан региона / ФК-ЦО → показываем тултип.
- нельзя выбрать капитана поставщика, пока не выбран капитан ФК.
- нельзя выбрать УИ-3, пока не выбран постоянный ФК.
- нельзя выбрать УИ-4, пока не выбран УИ-3.

Временный ФК
- если временный ФК выбран → поле периода становится обязательным;
- если временный ФК не выбран → поле периода необязательно.

Поставщики
- используется поиск и отображение: наименование / короткая аббревиатура / ИНН.

Геозоны
- если у родительской зоны нет дочерних → отображается одно поле;
- если есть дочерние → появляется второе поле (необязательное).

Сохранение
- при успешном сохранении отображаем снэкбар: «Информация отредактирована»;
- при ошибке – снэкбар: «Не удалось отредактировать информацию. Попробуйте позже».
- также добавляется обработка ошибки с бека.

4. Расширенный доступ

Мультикнопка «Расширенный доступ» располагается в верхней части раздела «Матрица ответственных».
Содержимое и доступные действия в этой кнопке зависят от текущей роли пользователя.

4.1 Роли и поведение мультикнопки «Расширенный доступ»

— Обычный сотрудник
Что видит в мультикнопке:
- Синий баннер. Текст: «Чтобы изменить информацию о себе, напишите своему руководителю [email]»
- Пункт меню «Запросить роль суперпользователя». Tooltip при наведении: «Если вам нужен доступ для редактирования всех сотрудников сети — необходимо запросить роль суперпользователя»
Поведение в таблице:
- Обычный сотрудник не видит карандаши в строках сотрудников.
- Редактирование недоступно.

— Руководитель
Руководитель может управлять администраторами своей группы.
Что видит в мультикнопке:
- Зелёный баннер. Текст: «У вас есть возможность управлять пользователями своей группы»
- Пункт меню «Назначить администраторов своей группы»
- Пункт меню «Запросить роль суперпользователя». Полностью повторяет флоу других ролей.

— Администратор (не руководитель)
Администратор может редактировать данные сотрудников своей группы.
Что видит в мультикнопке:
- Зелёный баннер. Текст: «Вы можете редактировать данные о себе и своих коллегах в Матрице ответственных»
- Пункт меню «Запросить роль суперпользователя». Поведение полностью идентично роли обычного сотрудника.
Поведение в таблице:
- Активные карандаши в строках сотрудников, которых можно редактировать.
- Замочек (disabled) в строках сотрудников, доступ к которым у админа отсутствует.

4.2 Флоу: «Запросить роль суперпользователя» (доступно для всех)
По нажатию открывается сайд-пейдж с формой.
Содержимое сайд-пейджа:
- Жёлтый баннер с текстом: «Если вам нужен доступ для редактирования всех сотрудников сети, необходимо запросить роль суперпользователя»
- Multi-select «Торговая сеть»: доступен множественный выбор (чекбоксы); варианты: Чижик, Пятёрочка, Перекрёсток; подпись: «Торговые сети, к которым необходим доступ»
- Textarea «Комментарий». Подсказка: «Укажите подробный комментарий, для чего нужен доступ»
- Кнопки: «Отменить», «Отправить»

Валидация:
- оба поля обязательны;
- незаполненные поля подсвечиваются красным + текст: «Поле обязательно для заполнения»;
- кнопка «Отправить» дизейблится, пока ошибки не исправлены.

После отправки:
Успех: сайд-пейдж закрывается, пользователь возвращается в таблицу, SnackBar (зелёный): «Запрос роли суперпользователя отправлен»
Ошибка: сайд-пейдж остаётся открытым, SnackBar (красный): «Не удалось отправить запрос роли суперпользователя. Попробуйте позже»

4.3 Флоу: «Назначить администраторов своей группы» (доступно только для руководителя)
По нажатию открывается сайд-пейдж.
Содержимое сайд-пейджа:
- Хедер: «Назначить администраторов своей группы»
- Серый подзаголовок: Указывает название группы. Пример: «Управление категорией «Ультра фреш»»
- Описание (текст): «Назначьте сотрудников, которым будет доступно редактирование данных вашей группы в разделе «Матрица ответственных». Например, изменение финансового кода, геозоны, УИ3, УИ4.»
- Multi-select «Администраторы группы»: показывает текущих админов (например, Пётр Петров Сергеевич, Додонова Юлия Дмитриевна); в дропдауне — остальные сотрудники группы; множественный выбор; можно добавлять и убирать админов.

Особенности селекта:
- отображается до 2 строк выбранных элементов;
- если выбранных больше → появляется чип-счётчик, например: +2;
- все выбранные сотрудники видны только в раскрытом меню.

Валидация: поле может быть пустым (допустимо снять всех администраторов).

Сохранение:
Успех: сайд-пейдж закрывается, появляется зелёный SnackBar: «Изменения сохранены»
Ошибка: сайд-пейдж остаётся открытым, появляется красный SnackBar: «Не удалось сохранить изменения. Попробуйте позже.»

4 (повтор нумерации в исходнике). Отображение уровня доступа в таблице
Для визуальной индикации роли используется звёздочка (по принципу олимпийских наград):
- Золотая звезда — Суперпользователь
- Серебряная звезда — Руководитель
- Бронзовая звезда — Администратор
Tooltip при наведении.

5. История действий (логирование)
Отражает изменения атрибутов сотрудников. Для каждой записи отображается:
- дата и время,
- сотрудник,
- параметр,
- прежнее значение,
- новое значение,
- инициатор.

5.1. Поведение таблицы логов
- hover на строке,
- длинные строки раскрываются тултипом при наведении,
- фильтры работают аналогично основной таблице.

5.2. Доступная фильтрация
- Дата: точная дата (одиночный календарь) или период (календарь с начальной датой и конечной),
- Сотрудник: точное совпадение + свободный ввод в инпуте,
- Инициатор: аналогично сотруднику.
- количество активных фильтров отображается в счётчике на кнопке после применения фильтров.

Кнопка «Сбросить фильтры» обнуляет фильтры до дефолтного состояния, таблица возвращается в исходное состояние без дополнительного нажатия «Применить».
Если ничего не найдено: информер «Ничего не найдено. Измените или сбросьте фильтры, чтобы увидеть данные» + кнопка «Сбросить фильтры».
