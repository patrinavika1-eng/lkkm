# ЛК Коммерсанта — пользователи
> Обновлено: 2026-10-10

## Аудитория
Сегмент B2E: внутренние сотрудники, связанные с категорийным менеджментом — категорийные менеджеры и их руководители. Источник: S-001.

Внешний участник — поставщик: пользователем ЛК КМ не является, но получает доступ на просмотр к договоренностям типа «Протокол», созданным КМ. Где именно он их видит — Неизвестно (Discovery.md H-012, Q-017). Источник: S-012.

## Тип описания
Портреты

## Ролевая модель
Подтверждена формальная ролевая модель доступа в разделе «Матрица ответственных» (в интервью называлась «Матрица доступов» — см. Discovery.md Q-005):

| Роль | Кто это | Цели и задачи | Права | Ограничения | Источник |
|---|---|---|---|---|---|
| Обычный сотрудник | Рядовой пользователь ЛК | Работа в своей зоне ответственности | Просмотр своих данных | Не может редактировать данные (ни свои, ни чужие) в «Матрице ответственных»; изменения — через обращение к руководителю; может запросить роль суперпользователя | S-008 |
| Администратор (не руководитель) | Сотрудник, которому делегировано редактирование | Поддержание актуальности зон ответственности своей группы | Редактирует данные сотрудников своей группы в «Матрице ответственных» (геозоны, финкоды, функции, УИ-3/УИ-4 и т.д.) | Не может редактировать сотрудников вне своей группы; может запросить роль суперпользователя | S-008 |
| Руководитель | Руководитель группы/подразделения | Управление группой и составом её администраторов | Как администратор + назначает/снимает администраторов своей группы | Назначение ограничено своей группой | S-008 |
| Суперпользователь | Выдаётся по запросу (процесс одобрения не описан) | Полный контроль над зонами ответственности сети | Предполагается редактирование всех сотрудников сети (прямо не детализировано) | Роль выдаётся по запросу через форму (торговая сеть + комментарий) | S-008 |

Визуальная индикация роли в таблице «Матрица ответственных» — звёздочка: золотая (суперпользователь), серебряная (руководитель), бронзовая (администратор); у обычного сотрудника звезды нет. Источник: S-008.

Отдельно в разделе «Матрица ответственных» встречается роль-статус «капитан» — сотрудник, ответственный за конкретный регион/ФК-ЦО, финкод или поставщика (влияет на маршрутизацию коммерческих предложений, ценовых спецификаций и PLU, упомянутую в Information-Architecture.md). Это атрибут ответственности, отдельный от ролей доступа выше. Источник: S-001, S-008.

«Панель администратора» (S-014, S-015): из меню профиля пользователь назначает администраторов своей группы — сотрудников, которым становится доступно редактирование данных группы в «Матрице ответственных» (финкод, геозона, УИ3, УИ4); это и есть роль «Администратор» из таблицы выше. На скриншотах панель открыта у пользователя с должностью «Директор департамента». По документации панель доступна пользователям с административной ролью, в том числе для подчинённых групп; по спецификации S-008 — только руководителю и только для своей группы. См. Discovery.md C-012, Q-022.

Права КМ в «Коммерческих предложениях» вытекают из «Матрицы ответственных»: КМ видит КП, если совпадают торговая сеть, геозона и финкод, а взять КП в работу может только при капитанстве по поставщику / финкоду (S-018). Подробно — Screens/Descriptions-Screen.md, Screen-006.

### Настраиваемые роли («Матрица доступов» → «Роли»)
В новой версии есть отдельная настраиваемая ролевая модель (S-029, S-030): роли (на скриншотах — Тестовая роль, Директор, Специалист, Категорийный менеджер; в макетах — Поддержка бизнеса) получают права отдельно для каждой связки «информационная система + раздел»: операции «Просмотр», «Редактирование», «Удаление» и области доступа «Нет / Свои / Все» по атрибутам «Торговая сеть», «Дирекция/Финкод», «Геозона», «Мой объект». Сотруднику можно назначить несколько ролей или оставить «Без роли». Как эта модель соотносится с уровнями доступа из таблицы выше — Неизвестно (Discovery.md C-023, Q-035). Подробно — Screens/Descriptions-Screen.md, Screen-008.
