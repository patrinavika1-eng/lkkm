# ЛК Коммерсанта — информационная архитектура
> Обновлено: 2026-10-10

## Доменная модель
| Сущность | Определение | Связи | Источник |
|---|---|---|---|
| Категория | Товарная категория, за которую отвечает КМ/руководитель категории | Связана с показателями, территориями, PLU | S-001 |
| PLU | Товарная позиция (артикул) — уровень детализации показателей | Входит в категорию, территорию | S-001 |
| Территория | Географический/организационный разрез показателей (геозона) | Связана с категорией, финкодом | S-001 |
| Финкод (дирекция) | Учётная единица, назначаемая сотруднику в Матрице доступов | Связан с сотрудником, территорией | S-001 |
| Договоренность | Документ или запись с согласованными с поставщиком условиями сотрудничества. Типы: «Протокол» (доступен поставщику, не изменяется) и «Прочее» (рабочая запись, видна только автору, изменяется); тип задаётся при создании и не меняется | Связана с поставщиком и автором (КМ); может иметь вложения, признак «Важное», статус просмотра поставщиком (для протокола) | S-001, S-012, S-013 |
| Коммерческое предложение (КП) | Набор товаров, которые поставщик предлагает X5 для закупки; имеет номер, статус, статус логистических условий, торговые сети, финкоды / дирекции, геозоны, срок, бэк-маржу | Связано с поставщиком; состоит из задач КП; доступ — через параметры «Матрицы ответственных» (торговая сеть, геозона, финкод, капитанство) | S-001, S-018, S-019 |
| Задача КП | Отдельный товар (SKU) из КП в разрезе торговой сети и геозоны; распределяется по КМ. Имеет номер, статус (Новое / В работе / Требует доработки / Принято / Отклонено), статус логиста, исполнителя (КМ), логиста, срок решения. Не путать с задачей «Задачника» | Входит в КП; назначается КМ и логисту; статусы задач определяют статус КП и статус логистических условий КП | S-018, S-019, S-020, S-021 |
| Ценовая спецификация | Запрос на изменение атрибута уже продаваемого товара (цена, регион поставки, НДС, квант) | Связана с товаром | S-001 |
| Роль доступа | Уровень прав в «Матрице ответственных»: Обычный сотрудник / Администратор / Руководитель / Суперпользователь | Связана с сотрудником, геозоной, финкодом/дирекцией | S-001, S-008 |
| Капитан | Статус ответственности сотрудника за регион/ФК-ЦО, финкод или поставщика; влияет на маршрутизацию КП/ЗПЦ/PLU | Связан с сотрудником, финкодом, поставщиком | S-001, S-008 |
| УИ-3 / УИ-4 | Уровни иерархии внутри финкода сотрудника (постоянный ФК → УИ-3 → УИ-4) в «Матрице ответственных»; возможна связь с одноимённым уровнем детализации на приборной панели — не подтверждено (см. Discovery.md H-001) | Связаны с финкодом сотрудника | S-008 |
| Задача | Единица работы для КМ; может иметь автоповтор, исполнителей, создаваться автоматически по скрипту | Связана с сотрудником | S-001 |
| Ключевой показатель | Показатель текущих результатов зоны ответственности: Выручка, Фронт-маржа, Потери (документация); на скриншотах также EBITDA | Имеет план (бюджетную цель), значение периода сравнения, набор опережающих показателей | S-009 |
| Опережающий показатель | Показатель, ухудшение которого заранее сигнализирует о возможном отклонении ключевого (доступность, товарный запас, SL и др.) | Принадлежит ключевому показателю; анализируется в срезах | S-009 |
| Срез | Разрез показателя по иерархии: категорийный (Категория → ФК → Группа дирекций → Дирекция → УИ3 → УИ4 → Вендор → PLU) или территориальный (Торговая сеть → Территория → Макрорегион → Дивизион) | Показывает вклад («влияние») каждого элемента в показатель | S-009 |
| Сигнал потерь | Индикатор риска: сумма потенциальных потерь (списаний) по причине — «Квант, не оборачиваемый за ОСГ», «ТЗ по поставкам РНР с риском списаний» | Рассчитывается по PLU, агрегируется по уровням среза | S-009 |
| KPI премии | Показатель с весом, от выполнения которого зависит премия (например, «Выручка итого по категории по ТС5», вес 35%) | Имеет план, факт, % выполнения, вклад в премию, статус; в разработке | S-010 |
| Группа | Группа сотрудников с администратором группы; бывают подчинённые группы | Связана с сотрудниками, администратором группы; иерархия подчинения | S-008, S-014 |
| Информационная система (ИС) | Система Орбиты, для которой настраиваются роли: ЛК Коммерсанта, Ассортимент, Ценообразование, Промо, Тендеры; имеет код (LKKM) и признак активности | Содержит разделы | S-029, S-030 |
| Раздел ИС | Часть ИС с собственными правами (для ЛК Коммерсанта — Договоренности, Матрица ответственных, Приборная панель, Личное дело поставщика, Коммерческие предложения, Ценовые спецификации); имеет код (LKKM.Agreements), тип процесса, признак активности | Входит в ИС; для каждой роли хранит права | S-029, S-030 |
| Роль (настраиваемая) | Набор прав (Директор, Специалист, КМ и др.) с кодом и признаком активности; права задаются для каждой связки ИС + раздел | Назначается сотрудникам (несколько ролей на сотрудника) | S-029, S-030 |

## Разделы продукта
| Раздел | Назначение | Пользователи | Связанные разделы | Источник |
|---|---|---|---|---|
| Приборная панель (сейчас главная страница) | Мониторинг состояния категории (или доступной категории) в территориальном и категорийном разрезах, вплоть до PLU. Вкладки «Ключевые показатели» (ключевые и опережающие показатели, AI-саммари, анализ срезов, динамика, бюджет) и «Сигналы» (риски потерь); в разработке — блок KPI премии с ИИ-саммари. Название подтверждено пользователем (S-011, C-007 разрешено) | КМ, руководители категории | Все разделы (сводная аналитика); Задачник (влияет на показатели) | S-001, S-009, S-010, S-011 |
| Договоренности | Фиксация согласованных с поставщиком условий: протоколы (видны поставщику, нельзя изменять) и рабочие записи «Прочее» (видны только автору); просмотр, поиск, фильтры, создание, редактирование «Прочего». В интервью — «внесение КМ и поставщиком… по сути заметки по поставщику» (см. Discovery.md C-011). Прежняя версия раздела называлась «Заметки» и больше не используется (S-016) | КМ, поставщик | Коммерческие предложения | S-001, S-012, S-013 |
| Коммерческие предложения | Обработка КП поставщиков: вкладки «Активные КП», «Архив», «История действий»; карточка КП с задачами; взять в работу, перераспределить, отправить на доработку, принять, отклонить (в том числе «в моей зоне»); аналитика, чаты с поставщиком | КМ (доступ по параметрам «Матрицы ответственных») | Матрица ответственных (определяет доступ), Приборная панель | S-001, S-018, S-019 |
| Ценовые спецификации | Операции по изменению атрибутов уже продаваемого товара: повышение цены, изменение региона поставки, НДС, кванта; принятие/отклонение | КМ | Коммерческие предложения | S-001 |
| Матрица доступов: вкладка «Матрица ответственных» | Роутинг КМов и руководителей для обработки коммерческих предложений, запросов на повышение цены, обработки PLU; назначение сотруднику геозоны, финкода/дирекции, функций, УИ-3/УИ-4, поставщиков; роль «капитан» по региону/ФК/поставщику; управление ролями доступа (Обычный сотрудник/Администратор/Руководитель/Суперпользователь) через «Расширенный доступ»; вкладка «История действий» — журнал изменений | Администраторы/руководители/суперпользователи (редактирование); все сотрудники (просмотр своей карточки) | Все разделы (управляет доступом) | S-001, S-008 |
| Матрица доступов: вкладки «Роли» и «Назначение ролей» | Настройка ролевой модели: ИС → разделы → роли с правами (Просмотр / Редактирование / Удаление по атрибутам Торговая сеть, Дирекция/Финкод, Геозона, Мой объект); назначение ролей сотрудникам | Неизвестно (Q-038) | Все разделы (права доступа) | S-029, S-030 |
| Задачник | Фиксация задач для КМов, автоповтор, назначение исполнителей, автозадачи по скрипту | КМ, руководители | Приборная панель (влияет на показатели) | S-001 |
| Панель администратора (вход через меню профиля в хедере, не через левый сайдбар) | Назначение администраторов своей группы — сотрудников, которые могут редактировать данные группы в «Матрице ответственных» (финкод, геозона, УИ3, УИ4); боковая панель поверх текущей страницы | Пользователи с административной ролью / руководители (см. Discovery.md C-012) | Матрица ответственных (тот же флоу «Назначить администраторов своей группы») | S-008, S-014, S-015 |

## Связи экранов и сущностей
- Screen-001 «Задачник» — сущность «Задача».
- Screen-002 «Матрица ответственных» — сотрудник, роль доступа, капитан, финкод, геозона, УИ-3/УИ-4.
- Screen-003 «Приборная панель» — ключевой и опережающий показатель, срез (использует ту же иерархию ФК → УИ3 → УИ4, что и Screen-002), сигнал потерь, KPI премии, PLU.
- Screen-004 «Договоренности» — договоренность (протокол / прочее), поставщик.
- Screen-005 «Панель администратора» — группа, администратор группы; результат влияет на права редактирования в Screen-002.
- Screen-008 «Матрица доступов: роли» — ИС, раздел, роль, сотрудник; права ролей действуют во всех разделах ЛК (в том числе «Личное дело поставщика», которое в контексте не описано).
- Screen-007 «Карточка задачи КП» — задача КП, товар, поставщик, логистические условия поставщика.
- Screen-006 «Коммерческие предложения» — КП, задача КП, поставщик; видимость и доступ определяются параметрами сотрудника в Screen-002 (торговая сеть, геозона, финкод, капитанство).
