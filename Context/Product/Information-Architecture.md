# ЛК Коммерсанта — информационная архитектура
> Обновлено: 2026-10-07

## Доменная модель
| Сущность | Определение | Связи | Источник |
|---|---|---|---|
| Категория | Товарная категория, за которую отвечает КМ/руководитель категории | Связана с показателями, территориями, PLU | S-001 |
| PLU | Товарная позиция (артикул) — уровень детализации показателей | Входит в категорию, территорию | S-001 |
| Территория | Географический/организационный разрез показателей (геозона) | Связана с категорией, финкодом | S-001 |
| Финкод (дирекция) | Учётная единица, назначаемая сотруднику в Матрице доступов | Связан с сотрудником, территорией | S-001 |
| Договорённость | Зафиксированные КМ и поставщиком показатели, документы, договоры | Связана с поставщиком | S-001 |
| Коммерческое предложение | Предложение поставщика на продажу товара | Связано с поставщиком, товаром, аналитикой, логистикой | S-001 |
| Ценовая спецификация | Запрос на изменение атрибута уже продаваемого товара (цена, регион поставки, НДС, квант) | Связана с товаром | S-001 |
| Роль доступа | Уровень прав в «Матрице ответственных»: Обычный сотрудник / Администратор / Руководитель / Суперпользователь | Связана с сотрудником, геозоной, финкодом/дирекцией | S-001, S-008 |
| Капитан | Статус ответственности сотрудника за регион/ФК-ЦО, финкод или поставщика; влияет на маршрутизацию КП/ЗПЦ/PLU | Связан с сотрудником, финкодом, поставщиком | S-001, S-008 |
| УИ-3 / УИ-4 | Уровни иерархии внутри финкода сотрудника (постоянный ФК → УИ-3 → УИ-4) в «Матрице ответственных»; возможна связь с одноимённым уровнем детализации на приборной панели — не подтверждено (см. Discovery.md H-001) | Связаны с финкодом сотрудника | S-008 |
| Задача | Единица работы для КМ; может иметь автоповтор, исполнителей, создаваться автоматически по скрипту | Связана с сотрудником | S-001 |
| Ключевой показатель | Показатель текущих результатов зоны ответственности: Выручка, Фронт-маржа, Потери (документация); на скриншотах также EBITDA | Имеет план (бюджетную цель), значение периода сравнения, набор опережающих показателей | S-009 |
| Опережающий показатель | Показатель, ухудшение которого заранее сигнализирует о возможном отклонении ключевого (доступность, товарный запас, SL и др.) | Принадлежит ключевому показателю; анализируется в срезах | S-009 |
| Срез | Разрез показателя по иерархии: категорийный (Категория → ФК → Группа дирекций → Дирекция → УИ3 → УИ4 → Вендор → PLU) или территориальный (Торговая сеть → Территория → Макрорегион → Дивизион) | Показывает вклад («влияние») каждого элемента в показатель | S-009 |
| Сигнал потерь | Индикатор риска: сумма потенциальных потерь (списаний) по причине — «Квант, не оборачиваемый за ОСГ», «ТЗ по поставкам РНР с риском списаний» | Рассчитывается по PLU, агрегируется по уровням среза | S-009 |
| KPI премии | Показатель с весом, от выполнения которого зависит премия (например, «Выручка итого по категории по ТС5», вес 35%) | Имеет план, факт, % выполнения, вклад в премию, статус; в разработке | S-010 |

## Разделы продукта
| Раздел | Назначение | Пользователи | Связанные разделы | Источник |
|---|---|---|---|---|
| Главная / Приборная панель | Мониторинг состояния категории (или доступной категории) в территориальном и категорийном разрезах, вплоть до PLU. Вкладки «Ключевые показатели» (ключевые и опережающие показатели, AI-саммари, анализ срезов, динамика, бюджет) и «Сигналы» (риски потерь); в разработке — блок KPI премии с ИИ-саммари. Название раздела не согласовано — см. Discovery.md C-007 | КМ, руководители категории | Все разделы (сводная аналитика); Задачник (влияет на показатели) | S-001, S-009, S-010 |
| Договорённости | Внесение КМ и поставщиком договорённостей по показателям, документов, договоров — по сути «заметки» по поставщику | КМ, поставщик | Коммерческие предложения | S-001 |
| Коммерческие предложения | Поставщик отправляет предложение на продажу товара; отображается аналитика по поставщику (если уже продаёт) и по предлагаемому товару, логистика поставщика; КМ принимает/отклоняет | КМ, поставщик | Договорённости, Ценовые спецификации | S-001 |
| Ценовые спецификации | Операции по изменению атрибутов уже продаваемого товара: повышение цены, изменение региона поставки, НДС, кванта; принятие/отклонение | КМ | Коммерческие предложения | S-001 |
| Матрица ответственных (в интервью — «Матрица доступов») | Роутинг КМов и руководителей для обработки коммерческих предложений, запросов на повышение цены, обработки PLU; назначение сотруднику геозоны, финкода/дирекции, функций, УИ-3/УИ-4, поставщиков; роль «капитан» по региону/ФК/поставщику; управление ролями доступа (Обычный сотрудник/Администратор/Руководитель/Суперпользователь) через «Расширенный доступ»; вкладка «История действий» — журнал изменений | Администраторы/руководители/суперпользователи (редактирование); все сотрудники (просмотр своей карточки) | Все разделы (управляет доступом) | S-001, S-008 |
| Задачник | Фиксация задач для КМов, автоповтор, назначение исполнителей, автозадачи по скрипту | КМ, руководители | Главная (влияет на показатели) | S-001 |

## Навигация и маршруты
| Откуда | Действие/условие | Куда | Источник |
|---|---|---|---|

| Приборная панель: плитка ключевого показателя | Клик | Выбор показателя для блоков «Опережающие показатели» и анализа | S-009 |
| Приборная панель: строка опережающего показателя | Клик | Блок анализа показателя внизу (Динамика / Анализ срезов / Детали по бюджету / Сравнение) | S-009 |
| Приборная панель: «Подробнее» в «Опережающих показателях» | Клик | Модальное окно «Опережающие показатели» | S-009 |
| Модальное окно «Опережающие показатели» / блок анализа / вкладка «Сигналы» | «Полный отчёт», «Открыть полный отчёт», «Открыть основной отчёт» | Внешний отчёт (открывается в новом окне; система — Неизвестно) | S-009 |
| Приборная панель: блок AI-саммари | «Запросить сводку» | ИИ-сводка (при DAY/WEEK/MTD и допустимом наборе фильтров) | S-009 |
| Приборная панель: карточка KPI | «Что сработало?» / «Как повысить?» / «Почему?» | Боковая панель с ИИ-саммари по KPI (в разработке) | S-010 |
| Приборная панель: блок премии | «О расчете премии» | Неизвестно (не показано) | S-010 |

Прочие маршруты неизвестны. Известна также групповая маршрутизация внутри «Матрицы доступов» (см. раздел выше).

## Связи экранов и сущностей
- Screen-001 «Задачник» — сущность «Задача».
- Screen-002 «Матрица ответственных» — сотрудник, роль доступа, капитан, финкод, геозона, УИ-3/УИ-4.
- Screen-003 «Приборная панель» — ключевой и опережающий показатель, срез (использует ту же иерархию ФК → УИ3 → УИ4, что и Screen-002), сигнал потерь, KPI премии, PLU.
